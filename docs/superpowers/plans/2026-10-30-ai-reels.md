# AI reels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Rev 3: rev 2 addressed the adversarial review (18 findings); rev 3 swaps Higgsfield voice/stitch (not in its API) for OpenAI voice + an ffmpeg copy-only join.

**Goal:** Make mobile page 02 (R01–R13) produce real AI reels: plan → Higgsfield render → self-approve by sending → Instagram or download.

**Architecture:** A studio reel is a `ContentItem` (`INSTAGRAM_REEL`, `studio = true`) whose version body carries the plan; agents that write posts ignore studio items. A `ReelRender` row per render attempt drives a step machine (voice → clips → join) through the job queue; voice (OpenAI) and join (ffmpeg, stream copy) run inside one job, clips (Kling on Higgsfield) are submitted with idempotency keys outside any DB transaction and polled. Approval, quality, credits and Instagram publishing reuse existing services with additive changes.

**Tech Stack:** Next.js 15 route handlers, Prisma/Postgres (Neon), vitest, Higgsfield REST, Expo (expo-router) + new `expo-video`, `expo-file-system`, `expo-sharing`.

**Spec:** `docs/superpowers/specs/2026-10-30-ai-reels-design.md`

## Global Constraints

- Screens stay as built; additions only: R06 "Downloaded · Posted it? Add link" line + one-field sheet, and R07 "Not right? Ask for changes" link → R04 (pending owner OK).
- Price is computed on the server: `Σ clipSeconds(speechSeconds(scene.voiceText)) × 2` credits. Scene `seconds` is derived, never client-set. Charged once per render attempt with `refId = ${versionId}:${attempt}`; refund on failure; "Try again" = new attempt = new charge (the failed one was refunded); redo = new version = new charge.
- Starter grant stays 20. `InsufficientCreditsError` → API 402 `{ needsPlan: true }` → app opens `/plans/reels`.
- `ReelPlan.scenes` 2–6 (the existing reel rule needs ≥ 2 script lines). Scene voice ≤ 30 words (≈ 15 s).
- Kling 3.0 Standard image-to-video `POST /kling-video/v3.0/std/image-to-video`, `sound: "off"`; fall back to Kling 2.6 Pro if Task 0 shows no 9:16.
- Higgsfield auth `Authorization: Key <id>:<secret>` (owner keeps both in `HIGGSFIELD_API_KEY_ID`), base `https://api.higgsfield.ai`; keys only in `apps/web/.env`, entered by the owner.
- No HTTP call to Higgsfield or OpenAI inside `prisma.$transaction`.
- Voice: OpenAI `gpt-4o-mini-tts`, WAV. Join: `ffmpeg-static`, video stream copy, no subtitles burned in (Instagram captions).
- Webhook = nudge only: re-fetch status with our key; download only from URLs passing `isHiggsfieldResultUrl`.
- Every `photoKey` must start with `${workspaceId}/${brandId}/` and match the media file-name pattern (as `publishing.ts:212-213`).
- Scheduled/published reels carry `videoKey` (not a URL) in the attempt target; signed at posting time. Client `videoUrl` is rejected for studio reels.
- While a render is running, plan edits and chat on that item return 409.
- Self-approval allowed for studio reels only.
- New strings English only. Commit messages: change + why, no trailers, never mention tests.
- Prisma commands run from `apps/web` (`npx prisma …`), not with `-w`.

## Review Focus

1. Webhook + poll + self-tick at once → one submit per step (Task 5 `claim is single-flight`).
2. Crash after Higgsfield accepted but before ids saved → never blind resubmit; stale claim → FAILED + refund + logged for a person (Task 5 `stale claim fails, never resubmits`).
3. Caption edit after render keeps `scenes`/`videoKey` and re-runs Quality for that item (Tasks 2, 6).
4. "Try again" after a refunded failure charges again; a double tap charges once (Task 2, Task 5).
5. Foreign `photoKey`, non-Instagram post link, link while SCHEDULED → rejected (Tasks 3, 6).

### Task 4: Video, voice and join clients

**Files:** create `server/reels/higgsfield.ts`, `server/reels/voice.ts`, `server/reels/wav.ts`, `server/reels/join.ts`; add dependency `ffmpeg-static` (web) and its `outputFileTracingIncludes` in `next.config`. Tests: `tests/reel-media.test.ts`.

**Produces:**
- `type HfStatus = { state: "queued" | "in_progress" | "completed" | "failed"; url?: string; error?: string }` (`nsfw` → failed with a message).
- `higgsfield.animate({ photoUrl, prompt, seconds, webhook, idempotencyKey }): Promise<string>` — `POST /kling-video/v3.0/std/image-to-video?hf_webhook=<enc>` with `{ image_url, prompt, duration, sound: "off" }`, header `Idempotency-Key`; returns `request_id`.
- `higgsfield.status(requestId): Promise<HfStatus>` — `GET /requests/:id/status`; `video.url` → `url`.
- Auth: `Key ${HIGGSFIELD_API_KEY_ID}` when it already holds `id:secret`, else `${ID}:${HIGGSFIELD_API_KEY_SECRET}`.
- `speak({ text, voice }): Promise<Uint8Array>` — OpenAI `POST /v1/audio/speech`, model `gpt-4o-mini-tts`, `response_format: "wav"`, French instructions ("Parle en français, ton calme et chaleureux, rythme posé."). `REEL_VOICES = ["coral", "sage", "ash", "ballad", "verse"]`.
- `wavSeconds(bytes)` — `(bytes.length − dataOffset) / byteRate` (OpenAI's streamed header has data size 0xFFFFFFFF, so the size field is not trusted).
- `padAndJoinWav(parts: Uint8Array[], seconds: number[]): Uint8Array` — each part's PCM padded with silence to `seconds[i]`, one WAV with a correct header. Parts must share format (asserted).
- `joinReel(clipFiles: string[], wavFile: string, outFile: string): Promise<void>` — `ffmpeg -f concat -safe 0 -i list.txt -i voice.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 128k -shortest -movflags +faststart out.mp4`, 60 s timeout, stderr tail in the error.
- `fetchResult(url): Promise<Uint8Array>` — https only, host not private (reuse the crawl guard), `redirect: "error"`, 100 MB cap.

### Task 5: Render engine

**Files:** create `server/reels/render.ts`; register in `server/jobs/runner.ts`; migration replacing the step enum. Test: `tests/reel-render.test.ts`.

**Consumes:** Tasks 2–4; `putMedia`, `mediaKey`, `signedMediaUrl`, `enqueueJob`, `startAgentRun`, `lock`/`TX` from publishing; `sharp` (crop to 1080×1920).

**Produces:**
- Schema: `enum ReelRenderStep { VOICE CLIPS JOIN DONE FAILED }` (table is empty; recreate the type). `outputs` = `{ voiceKeys: string[], voiceSeconds: number[], photoKeys: string[], clipUrls: string[] }`.
- `REEL_RENDER_JOB = "reel.render"`.
- `startRender({ workspaceId, brandId, userId, itemId, version })` — under `lock(item)`: latest version, `isStudioPlan`, `planProblems` empty, no render of the item in VOICE/CLIPS/JOIN (409). `attempt = 1 + max`; `spendCredits({ amount: reelPrice, reason: "reel-render", refId: "<versionId>:<attempt>" })`; create row; `enqueueTick`.
- `enqueueTick(render, delayMs = 0)` — increments `ticks`, `enqueueJob` with key `reel:<id>:tick:<ticks>`.
- `nextStep(render, statuses)` — pure: VOICE → `voice`; CLIPS with no ids → `submit` (or `wait` if `claimedAt` < 2 min old; ≥ 2 min → `submit` again, safe: same Idempotency-Keys); CLIPS ids: any failed → `fail`, all completed → `join` with urls, else `wait`; JOIN → `join` (retry after a crash).
- `advanceRender({ renderId })`:
  - **voice** (no Higgsfield): per scene `speak` → `putMedia` WAV, `wavSeconds`; crop each scene photo to 1080×1920 → `putMedia`; CAS `step VOICE → CLIPS` + outputs; tick now.
  - **submit**: claim with `updateMany({ where: { id, step: "CLIPS", claimedAt: <as read> }, data: { claimedAt: now } })`, count 1 or return; with no transaction open, `animate` per scene, `idempotencyKey: "<renderId>:clip:<i>"`, `seconds: clipSeconds(voiceSeconds[i])`; save `requests.CLIPS`; tick +20 s.
  - **wait**: tick +20 s. Give up only on a failed status or 24 h since `createdAt`.
  - **join**: CAS `CLIPS → JOIN`; download clips (`fetchResult`) and voices to a temp dir; `padAndJoinWav` to each clip's length; `joinReel`; `putMedia(mediaKey(scope, "<uuid>.mp4"))`; under `lock(item)` + `TX`: new version = rendered body + `videoKey`, `createdBy: "agent"`, item `DRAFT_REVIEW`, render `DONE` + `videoKey`; then `startAgentRun({ agentKey: "quality", trigger: "event", input: { itemId } })`. Temp dir removed in `finally`.
  - **fail**: FAILED, `error`, `refundCharge`, AuditEvent `reel.render.failed`.
- `failRender(payload, error, exhausted)` — job `onFailure`; exhausted → fail.
- `renderView(itemId)`.

- [ ] **Step 1: Failing tests:** `nextStep` table (VOICE → voice; CLIPS no ids → submit; fresh claim → wait; 3-min-old claim → submit; one failed → fail; all completed → join); `claim is single-flight` (count 0 → no `animate`); `resubmit reuses idempotency keys`; `resume polls stored ids`; `startRender twice` → one charge; `try again charges a new attempt`; `failure refunds`; `join starts quality for the item`; `edits blocked while rendering`.

### Task 4b: Scene router, model adapters, prompt check, mixed join

**Files:** create `server/reels/router.ts`, `server/reels/prompt-check.ts`; modify `server/reels/higgsfield.ts`, `server/reels/join.ts`, `server/reels/plan.ts`. Test: `tests/reel-router.test.ts`.

**Produces:**
- `SceneKind = "detail" | "room" | "physics"`; `ReelScene` gains optional `kind`, `prompt` (≤ 1200 chars), set by the director.
- `VIDEO_MODELS: Record<ModelId, { path; minSeconds; maxSeconds; allowed?: number[]; body(input): object }>` for `kling-3-std` (`{ image_url, prompt, duration, sound: "off" }`), `seedance-2.5` (`{ image_url, prompt, duration, resolution: "1080p", generate_audio: false }`), `hailuo-2.3` (`{ image_url, prompt, duration }`, allowed 6/10).
- `routeScene(kind): ModelId` — detail → kling-3-std, room → seedance-2.5, physics → hailuo-2.3. `BACKUP_MODEL = "kling-3-std"`.
- `modelSeconds(model, voiceSeconds): number` — clamp to the model's range; for `allowed`, the smallest allowed ≥ voice (else the largest).
- `higgsfield.animate({ model, photoUrl, prompt, seconds, webhook, idempotencyKey })` — uses `VIDEO_MODELS[model]`.
- `promptProblems(model, prompt): string[]` — > 1200 chars; negative phrasing (`/\b(no|without|don't|pas de|sans)\b/i`); re-describing the still (starts with "a photo of"/"an image of"); refusal triggers (brand/celebrity names list kept short).
- `joinReel(clips, wav, out, { reencode })` — `reencode` → `-vf scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2,fps=30 -c:v libx264 -preset veryfast -crf 20`, each clip trimmed to its scene seconds via concat `outpoint`; else stream copy as today.
